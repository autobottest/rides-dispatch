# Repository context for AI agents and reviewers

This repo holds the pricing and dispatch services for a ride-hailing platform.

- Pricing code (`src/pricing/`) is revenue-critical. Changes must follow `docs/STANDARDS.md`: no PII in logs, feature-flag pricing changes, and audit every price override.
- Use `logger` from `src/lib/logger.ts` for all logging. Never log `riderPhone`, `riderEmail` or other personal data.
- `generated/` is produced by the zone-sync job. Do not review or hand-edit it.
- Each pull request should reference a Jira work item key (e.g. RIDE-142) and satisfy that item's acceptance criteria.
