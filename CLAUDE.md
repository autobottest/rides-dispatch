# Instructions for Claude Code

Before changing code in this repo:
1. Read `docs/STANDARDS.md` and follow every standard (STD-01 no PII in logs, STD-02 feature-flag pricing changes, STD-03 audit price overrides).
2. Read `.agent.md` for repository context.
3. Fetch the linked Jira work item (and any linked Confluence spec) through the Atlassian MCP server, and implement every acceptance criterion.
4. Put the Jira key in the branch name, commit message and PR title (e.g. `RIDE-1: ...`).
